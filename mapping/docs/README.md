# Sovereign Florida Map Stack

A fully sovereign, end-to-end geospatial pipeline that extracts, processes, and serves vector tiles for the state of Florida. Built for cockpit integration, real-time overlays, and long-term extensibility.

---

## Features

- Custom tile generation pipeline (tilegen)
- Modular layer architecture
- MapLibre-compatible style system
- Local tile server with gzip + caching
- Clean directory structure for future expansion
- Documentation for every subsystem
