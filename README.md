# Sovereign Rover Project 🚀

## Overview
This repository documents the lineage of my rover project — from hardware wiring to networked autonomy — framed as Stardate logs and sovereign rituals.

## Current Capabilities
- Remote control of 750W drive motor via WS55-220 driver
- Direction toggling through optocoupler circuit (Arduino pin 24)
- ngrok tunneling for distributed command/status protocol
- GUI + Arduino sketches scaffolded for actuator subsystem
